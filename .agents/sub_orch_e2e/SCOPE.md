# Scope: E2E Testing Track

## Architecture
- Design a comprehensive opaque-box test suite for the Religious Wiki Extraction project.
- Tests must verify:
  1. All 47 mapping.json items were processed.
  2. Narrative information was non-destructively added to primary text pages.
  3. Figure pages were created with correct YAML frontmatter.
  4. Figure pages were appended to wiki/index.md.
- Output TEST_INFRA.md and finally TEST_READY.md.
